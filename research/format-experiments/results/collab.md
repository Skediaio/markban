# Collaboration simulation

Generated by `collab_sim.py` (deterministic seeds). Writers own disjoint cards, so every missing effect is a lost update
(an op later overridden by the same writer is excluded). A lost op can cascade: a later op that anchors on it may also fail.
In format B, concurrent inserts into the same gap can pick equal `order` values; ties sort by id, so "X above Z" can silently flip (counted as lost).

## S1: shared directory

Ops are interleaved at read-file / write-file granularity. naive = overwrite whole file from the stale read; CAS = re-read the file about to be written and retry the op if it changed; string-replace = apply the exact old->new snippet to the CURRENT file, abort the op (no retry) if the snippet is gone or ambiguous. `silently lost` = no error reported but the effect is missing at the end.

## S2: git branch per agent

Each branch applies 5 ops serially and commits once; main merges b0..bN sequentially (`git merge`). A conflicting merge is aborted (that branch's ops are dropped and counted as aborted, not as silent loss). `union` = `.gitattributes` merge=union committed on main first. Validity is checked with the format parser.
